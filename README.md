## 云服务器推荐哪家，先回答一个问题：你的用户在哪，业务要不要备案

服务中国大陆用户的网站要走备案，国内厂商在备案接入、售后和生态配套上更省事；主要用户在海外，就优先选离用户近的海外机房。这条分界线比任何“性价比排行榜”都管用。

国内大厂这一侧，活动期通常有百元级的年付入门机，配置集中在 2 核 2G 到 4 核 4G，带宽多为个位数 Mbps，具体机型和价格随活动档期变化，得看当期活动页。好处是生态齐全：对象存储、CDN、云数据库、短信服务、备案接入都在一个控制台里，出问题有工单和电话。

境外中国优化这一侧，卖的是另外三件事：不涉及国内备案流程、端口从 1Gbps 起、回程走 CN2 / 9929 / CMIN2 这类优质骨干。代价是价格高一个数量级，而且没有国内大厂那套配套——没有备案接入，没有托管数据库，没有短信服务。

| 维度 | 国内大厂 | 境外中国优化（如 GoMami） |
| --- | --- | --- |
| 备案 | 网站需备案接入 | 不涉及国内备案流程 |
| 入门价格 | 活动期有百元级年付入门机，以当期活动页为准 | $29/月起（日本 / 新加坡 / 洛杉矶 Nano） |
| 端口 | 多为个位数 Mbps | 1Gbps 起，高档到 10Gbps |
| 生态 | 对象存储、CDN、云数据库、短信齐全 | 只有 VPS 与独立服务器 |
| 大陆访问 | 直连，国际出口一般 | 回程走 CN2 / 9929 / CMIN2 |

两条路线的价格差不是同一个维度上的竞争。如果你的项目是个人博客、跑个脚本、放个小程序后端，并且用户就在国内，国内大厂的入门机完全够用，没必要为线路质量多掏二十几倍的钱。反过来，如果你的付费用户在大陆、访问体验直接影响转化，那省下来的那点钱会在晚高峰还回来。

## 线路、晚高峰，以及怎么在不买之前先测一遍

所有 VPS 套餐在商店页都标着 “China Mainland Optimized Pro”，也就是面向中国大陆的三网优化。官方对 Turin 的说明是对 CN2 / 9929 / CMIN2 做深度优化，官网首页写的是全大陆 RTT <50ms。

第三方整理的路由表更具体一些（以下为第三方说法，官方页面只笼统写“三网优化”）：香港、日本、新加坡走的是“去程直连 + 回程精品”，电信回程 CN2、联通回程 9929、移动回程 CMIN2；洛杉矶则是三网双程都走精品。这套取舍的逻辑是，大多数网站和应用场景里，决定“感觉快不快”的是回程方向。

延迟数字上也要留个心眼。官网标称 <50ms，第三方按地区给出的估算区间是华南 40–60ms、华东 50–70ms、华北 70–90ms。华北那一段跟官网口径并不完全一致，官网是营销口径，第三方是估算，两边都不是原始实测数据。

真正能自己验证的入口是官方提供的独立 Looking Glass 测试页，可以按节点选跑 Ping、TCPing、MTR、NextTrace、Traceroute，不用买就能用。买之前按这四步测一遍，比看任何测评都准：

1. 从你真实用户所在地区测延迟，别用自己办公室的机器代替。
2. 在北京时间晚上 20:00–23:00 测一遍。这个时段是便宜机房掉速的分水岭，也是这类产品值不值钱的关键。
3. 做持续吞吐测试，看能不能跑满标称端口，而不是只看单次 ping 值。
4. 从中国 IP 做 traceroute，看路径里有没有 CN2 / AS9929 / CMIN2 的跳点，还是挤在 163 骨干上。

如果只跑数据库、游戏服这类对单核频率敏感的业务，Turin 那条线更对口，官方对它的定位就是“高负载、高并发、低延迟”。👉 查看香港 Turin 各档配置与当前价格

## 钱怎么算：流量口径、计费周期、退款和优惠码

流量只计算出站，入站不计费，额度在每个账单周期开始时重置。这一条很多人没注意——如果你主要对外提供下载或视频，出站流量才是真正的成本项。不够用时可以单独买流量包，不必升级套餐：100GB $6、500GB $30、1TB $60、2TB $120、5TB $300、10TB $600、20TB $1200，折算下来统一是 $0.06/GB。

计费周期有月付、季付、半年付、年付四档，官方文档只说“更长周期通常更便宜”“年付最省”，没有公布具体折扣率。官方 Billing FAQ 给出的口径是年付相比月付通常省 15%–20%，具体比例按产品线不同。任何精确到个位的“年付省多少”都还是推算，下单时以结账页显示的金额为准。

退款政策是 24 小时内可申请全额退款，条件比较细：仅限新购的首次订单、每人一次，续费订单不适用；超过 24 小时、因违反服务条款被终止、已使用的账户余额、因 DDoS 被黑洞的 IP 都不在退款范围内。到账时间支付宝 1–3 个工作日、信用卡 5–10 个工作日、加密货币 1–3 个工作日。退款批准后实例和数据立即永久删除，申请前记得先备份。

优惠码方面，官方页面只确认了结账流程里存在 Promo Code 输入框，没有公开具体码值。第三方流传的两个码是 `Hi,LAX`（洛杉矶 Pulse 系列 8 折，测评称支持月付，按折扣折算后 Nano 约 $23.20/月，这是第三方折算价，不是官网报价）和 `GOMAMI365`（年付折扣）。后者两处来源说法冲突：一处说全线年付 8 折循环，另一处说只适用香港 Turin 年付 8 折。两个码都不是官方明示，能不能用、适用哪些套餐，只能在结账页的 Promo Code 框里现场验证。
